# Fanfande_Agent : 从0开始搭建的AI Agent

<br />
<div align="center"
  <p align="center">
`Fanfande_Agent` 是一个追求**完全透明、无黑盒**的 AI Agent 极简实现。该项目拒绝除 LLM 和外部 MCP 服务以外的一切黑盒封装，旨在通过最底层的 Prompt Engineering 和逻辑循环，展现 AI Agent 是如何通过放大 LLM 的推理能力，在现实世界中解决问题的。
  </p>
</div>
